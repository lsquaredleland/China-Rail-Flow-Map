# Self-hosted fonts

- `AVHersheySimplexMedium.otf`: Hershey Simplex (A. V. Hershey's plotter lettering, 1967),
  outlined by Stewart Russell as AVHershey-OTF, https://github.com/scruss/AVHershey-OTF,
  dual-licensed CC0 / WTFPL. Used by the terminal skin's CRT look (default; `?fx=off` drops it) (registered as
  'CRT Face' in `src/lib/fx.ts`).
